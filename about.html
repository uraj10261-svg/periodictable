About ELEMENTA & Scientific Methodology

ELEMENTA is an interactive scientific platform and periodic table designed for students, educators, chemists, and physics researchers. Built with pure client-side web technologies (HTML5, CSS3, Vanilla ES6+ JavaScript), it operates entirely without external server dependencies, guaranteeing zero tracking and full offline reliability.

1. User Guide & Key Features

Interactive Periodic Table

The main periodic table presents all 118 officially recognized chemical elements in the standard 18-column, 7-period layout. The f-block elements (Lanthanides 57–71 and Actinides 89–103) are placed in two rows below the main body, with clear series placeholders at group 3 periods 6 and 7.

Hover & Tap Previews

Moving the mouse cursor over any element tile activates an intelligent floating preview card. The card calculates viewport collisions dynamically, ensuring it never clips against the screen edge. You can pin the card open using the pin icon, allowing you to examine values while interacting with other elements. On touch devices, a single tap displays the preview card.

Live Search & Auto-navigation

The search system operates in real time across element names, chemical symbols, and atomic numbers. Using the keyboard (Arrow Up, Arrow Down, Enter) allows rapid navigation through matching elements, smoothly scrolling the periodic table and focusing the selected tile.

Property Visualization (Heatmaps)

Selecting a physical quantity (such as atomic mass, density, melting point, boiling point, electronegativity, or atomic radius) switches the table into continuous heatmap mode. A scientific color ramp highlights periodic trends across groups and periods, with unavailable values clearly distinguished.

2. Scientific Interpretation of the Bohr Model

Each element profile features an interactive SVG Bohr atomic model showing concentric electron shells (K, L, M, N, O, P, Q). The electron count per shell is calculated directly from the ground-state electron configuration.

Educational Disclaimer: The Bohr model is a pedagogical semi-classical visualization. In contemporary quantum chemistry, electrons do not orbit in fixed circular tracks; rather, their spatial distribution is governed by Schrödinger wavefunctions representing three-dimensional probability density clouds (atomic orbitals).

3. Units and Measurement Conventions

To maintain strict scientific consistency, ELEMENTA follows standard International System of Units (SI) conventions:

  • Atomic Weights: Expressed in unified atomic mass units (u or Da). For elements with no stable isotopes, the mass number of the longest-lived isotope is indicated in brackets [A].
  • Temperatures: Expressed primarily in Kelvin (K), with Celsius (°C) equivalencies provided on profile pages. Standard reference conditions: 298.15 K (25 °C) and 101.325 kPa (1 atm).
  • Densities: Expressed in grams per cubic centimeter (g/cm³) for solids and liquids at 293 K, or grams per liter (g/L) for gases at standard temperature and pressure.
  • Electronegativity: Pauling dimensionless scale (values range from 0.7 for francium to 3.98 for fluorine).
  • Ionization Energies: Expressed in kilojoules per mole (kJ/mol) for first valence electron extraction.
  • Atomic Radii: Calculated and empirical radii expressed in picometers (pm).

5. Missing Data Conventions & Confidence

For transuranic and superheavy elements (elements 104 through 118), macroscopic quantities have never been synthesized; many exist only for fractions of a second in particle accelerators. In these instances, ELEMENTA marks properties as:

  • Measured: Experimentally determined value with reproducible peer-reviewed results.
  • Reference: Standard internationally accepted convention (e.g. Pauling scale, atomic mass standards).
  • Predicted: Value calculated via relativistic Dirac-Fock quantum chemical models.
  • Unavailable: Value is neither measured nor reliably projected; displayed as null/unavailable rather than inventing synthetic numbers.
